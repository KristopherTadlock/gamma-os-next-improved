PACK-IN GAMES
=============

gamma-os-next-improved bundles one game per platform. Each game's rights
holder explicitly allows it to be redistributed, and none uses another
company's characters, names, or assets. Each game is installed with its full
license text next to it (<game file>.license.txt).

None of these games has been tested on the RG Cube yet.


GAMES
-----

Game Boy
  Big2Small, by Matthew D. Steele
  A 40-level puzzle game.
  License: GPL-3.0. Art and music derived from CC0/public-domain sources.
  Source: https://github.com/mdsteele/big2small

  Tobu Tobu Girl Deluxe, by Tangram Games (music by potato-tan)

  Source: https://github.com/SimonLarsen/tobutobugirl-dx

  An action-adventure game with 5 dungeons.

PLATFORMS WITHOUT A GAME
------------------------

WonderSwan / WonderSwan Color
  Snail Maze+ adapts Sega's Snail Maze, Wonder Breakanoid is an unfinished
  Arkanoid clone, and Inufuto's games have no license.
Nintendo 64
  Games built with Nintendo's SDK contain Nintendo's code. The other games
  found show the Nintendo 64 logo or use music of unverified origin.
PlayStation
  The homebrew found has no license, uses Sony's SDK, or copies other games.
3DO
  The one licensed game includes the 3DO Company's operating system files.
Arcade
  The MAME project's free ROMs may only be distributed from mamedev.org.
  Users can download them there: https://www.mamedev.org/roms/
