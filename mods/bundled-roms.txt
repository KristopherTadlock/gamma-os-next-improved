# Games bundled in /sdcard/ROMs (installed on first boot from roms.tar.xz):
# one per platform, each with an explicit grant to redistribute it and no
# third-party characters, names, or assets. Comment a line out to drop it.
#
#   upstream  <system>/<file>  license=<url>
#       Keep a game from the GammaOS Next v1.2 ROM pack (checked against the
#       author's official release).
#   add  <system>/<file>  url=<download>  sha256=<of the file>  [member=<file in archive>]  license=<url>
#       Download, verify, and add a game.
#   tree  <system>/<folder>/  url=<download>  sha256=<of the download>  member=<folder in archive>  license=<url>
#       Download, verify, and add every file in a folder of an archive.
#   local  <system>/<file>  license=<url>
#       Add a file kept in rom-files/.
#   folder  <system>
#       Create an empty ROMs folder (for platforms without a pack-in game).
#
# Every game ships with its license notice; GPL games also get a source link.
# Only Anarch (3DS) has been confirmed to run on the device so far.
