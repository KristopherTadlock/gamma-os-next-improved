# Box art, screenshots and details for the pack-in games in bundled-roms.txt,
# installed with them on first boot: ES-DE game lists and media in /sdcard/ES-DE
# (the ES-DE theme and ES-DE read them), and on the 1.4.4 base, Nano's box art
# index for its other themes. A scrape with Overwrite on replaces them.
#
#   [<system>/<file>]       a game in bundled-roms.txt
#   title = ...             developer = ...     publisher = ...
#   released = YYYY or YYYY-MM-DD (when the game first came out)
#   genre = ...             players = 1, 1-2, ...
#   desc = one line, written for this list
#   cover, screenshot, titlescreen, marquee = an image, either
#       url=<image>  sha256=<of the image>  license=<url>
#       file=<image in pack-in-art/>  license=<url>
#
# Downloaded images come only from each game's own project (its repository,
# release page or author's site), under the game's license; none from game
# databases, which don't allow redistributing their media, and none with other
# companies' marks or a third party's art. The rest are made from the games
# themselves (tools/pack-in-art): screenshots and title screens captured from
# the bundled ROMs with capture.py, and box art and marquees drawn by
# make_boxes.py in the style of each console's boxes, around the game's own
# title screen, art or screenshot, with no console or publisher logos.
