# RetroArch cores to ship. One core per line; "D - core" marks the default
# core for its system. Comment a line out to drop it. Any other core on the
# libretro buildbot (nightly/android/latest/arm64-v8a) can be added by name.
# Listed cores are updated to the latest buildbot nightly at build time.
#
# The build sets each Daijisho platform's default player to its "D - " core.
# Dreamcast, N64, DS, and PSP keep their standalone apps as the default.
# Sizes are uncompressed.
