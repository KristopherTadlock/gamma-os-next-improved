# out to drop it, or uncomment an alternative to add it. Any other core on the
# libretro buildbot (nightly/android/latest/arm64-v8a) can be added by name.
# Listed cores are updated to the latest buildbot nightly at build time.

# that core breaks the platform until its Daijisho default is changed.
