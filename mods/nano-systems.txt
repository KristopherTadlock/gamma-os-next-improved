# Game systems in the GammaOS Nano home, in this order (1.4.4 base only).
# First-boot setup seeds them into /data/system/nano_systems.json; Nano's
# Game Systems editor can change them after that. Nano hides a system until
# its folder has games.
#
#   <ROMs folder>  name=<shown in Nano>  short=<short name>  icon=<icon>  player=<unique ID>
#   <ROMs folder>  name=...  short=...  icon=...  package=<app>  intent=<am start arguments>  exts=<.a,.b>
#
# A player is one of Nano's emulator catalog entries (Daijisho's platform
# definitions, /system/etc/nano_xmb/daijishou); the build checks its core is
# in retroarch-cores.txt or its app is installed. In an intent, {file.uri} is
# the game's content URI and {file.path} its path. icon=builtin:<n> is one of
# Nano's own icons, icon=retroarch:<name> one in /system/etc/nano_xmb/icons_retroarch.
#
# The first 15 are Nano's own systems, in its order, with this project's
# default emulators. The N64, PSP and Dreamcast intents are Nano's own.
# ScummVM and PS Vita aren't listed: their players pass each game's ID, which
# Nano can't, so those games start from the ScummVM and Vita3K apps.
